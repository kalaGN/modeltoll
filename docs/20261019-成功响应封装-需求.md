# 成功响应封装需求

用户确认：按已给出的 success 辅助函数方案修改，并分析其他类似优化点。

范围：管理类 API 的平铺成功响应统一由 api/responses.py 构造；支持 ok/created，
不加 data 层，不修改路径、字段、状态码、Cookie、头或错误体。
覆盖认证、个人 Key、品牌、管理员、连接配置及统计 API。
推理、OpenAI 兼容输出、Logo、health 不包装；不使用全局中间件。
其他优化仅审查并给建议，不顺带改错误处理、请求体限制、分页或业务服务契约。

验收：公共函数有独立测试；认证/Cookie/201、Key/统计响应回归通过；
完整 OpenAPI 相同；默认回归不退化。无新依赖，不触碰真实数据、模型或现有服务。
