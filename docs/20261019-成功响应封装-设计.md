# 成功响应封装设计

用户已确认前一轮方案；目标与边界见[需求](20261019-成功响应封装-需求.md)。

公共函数位于 backend/app/api/responses.py，采用现有四空格、类型注解风格：

```python
def success(*, code: str = "ok", **payload: Any) -> dict[str, Any]:
    return {"code": code, **payload}
```

它只创建新字典，显式传入 code 供 created 及已有服务结果使用，不自动 JSON 编码、
不添加字段或响应头。JSONResponse、201 与 Cookie 操作仍由原路由掌握。
管理员业务服务目前自带 code；_call 在 API 边界将原字典交给 success，暂不改服务接口。
统计页展开保留原顺序，服务结果不引入同名重复关键字。所有错误、模型输出和图片保持原路径。

先保存 OpenAPI 并增加行为基线，再实现公共函数并替换字典构造。新增函数无事务副作用，
不改依赖、数据库和模型锁；回滚只恢复本轮辅助函数与调用点，无数据回滚。
