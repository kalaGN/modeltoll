## 目标与范围

修复已核实的跨路由私有依赖、schemas 反向依赖服务、网关持久化与 HTTP 传输混合、
恢复跨服务调用私有结算接口、品牌与管理员总览混合及 db/models.py 命名误导。
保持 API、业务规则和事务行为不变，不全面套用此前分层草案的目录树。

## 验收

- 路由不导入其他路由；共享推理 HTTP 协调有明确归属。
- schemas 不导入 services；邮箱规范化、长度与格式规则不变；SettingsRequest 归入 schemas。
- 上游 HTTP 适配器不依赖服务或数据库；保留 TLS、超时、大小、重定向和用量验证边界。
- 正常与恢复结算共用公开的内部业务接口和原事务游标，不新建独立事务。
- 公开品牌路由与管理员路由分开；品牌服务不混入管理员总览 SQL。
- db/migrations.py 执行原有迁移；SQL 文件、顺序和启动行为不变。
- 迁移前后完整 OpenAPI 相同；原有回归保持，新增静态边界测试及独立适配器测试。

## 非目标

不改部署迁移策略，不搬模型运行时、不增加业务子包/ORM/Repository/依赖；
不改数据、.env、限额或计费策略。不提交、推送、部署或重启现有服务。
