# 管理员后台需求

日期：2026-10-07。状态：用户已要求管理员字段、登录分流与管理页面；用户已确认平台总览方案，随后追加平台配置页面，并通过“开发吧”授权实施。

## 目标与现状

users 当前只有账号状态，没有管理员角色。登录返回 user{id,email}，页面统一进入 /keys。新增是否管理员字段，管理员登录后显示平台管理页面；普通用户保持个人控制台。

## 首版范围

- users.is_admin 布尔值默认 false，既有账号保持普通用户。注册请求不接受角色赋权。
- 服务端会话每次读取当前角色，禁止以浏览器状态或请求参数获得管理员权限。
- 管理员默认进入 /admin；普通用户仍进入 /keys。管理员可返回个人控制台。
- 页面仅做平台总览：账号总数、可用密钥数、时间窗口调用数与费用；展示按 UTC 日调用量和费用趋势。
- 支持时间窗口；所有平台数据只允许管理员读取。费用由服务端 Decimal 计算，前端展示。
- 首版不含账号列表、邮箱搜索、角色修改、停用账号、创建账号、修改价格、查看完整密钥或客户原文。若用户选择管理操作，先补充操作契约及最后一个管理员保护。

## 验收

1. 普通用户、未登录用户无法访问平台接口；分别返回 403 与 401。页面未登录跳转登录，普通用户访问 /admin 返回 403。
2. 登录、注册及 me 响应新增 user.is_admin 布尔值，旧字段不变；管理员登录后进入 /admin。
3. 直接伪造注册 is_admin、URL 参数或前端状态不能授予管理员权限。
4. 移除管理员角色后，原会话下次请求立即失去管理访问权限。
5. 普通用户个人统计仍受 user_id 隔离；管理员的平台接口与原接口分开。
6. 无数据、加载中、失败、窄屏均有可用状态；不展示虚构业务指标。

## 2026-10-07 追加：平台配置

管理员后台增加平台配置页，允许修改平台名称、平台 Logo 及平台简介。属于平台品牌配置，不涉及价格、推理模型、权限规则或密钥。

- 平台名称必填，去首尾空白，1–60 字符；简介可空，最多 200 字符。默认名称 Laya，默认保留现有 Logo 和中文简介。
- Logo 支持 PNG/JPEG/WebP 上传、预览及恢复默认，最大 2 MB；首版不支持 SVG、远程图片 URL 或任意 HTML。
- 保存成功后，刷新登录页、个人控制台、管理员后台使用统一品牌；浏览器页签标题同步平台名称。
- 保存仅管理员可用，要求会话与 CSRF；普通用户和匿名用户只能读取展示所需的三个品牌字段。
- 表单显示保存中、成功与失败反馈；失败保留输入，不伪报成功。保存前提供本地品牌预览。
- 不增加账号列表、角色调整、停用账号等功能。

实施范围补充：统计窗口最多 366 天；每日表格为趋势的可访问数值表示，不展示账号列表。Logo 验证新增 Pillow 依赖，声明与回滚见设计。
