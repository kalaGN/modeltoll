# 已撤销 API Key 删除

日期：2026-10-07。状态：用户已确认软删除方案，已实施。

## 目标与事实

用户要求已撤销 API Key 可以删除。当前只有创建、列表、撤销；api_calls 通过外键引用 api_keys，统计明细也 JOIN api_keys，不能物理删除关联密钥或删除历史账务。

## 拟定范围

- 仅本人已撤销 Key 可删除；可用 Key 先撤销后删除。
- 删除采用 deleted_at 标记，从 Key 管理列表、数量与筛选选项中移除；无法在页面恢复。
- 保留密钥数据库行和历史调用、费用、脱敏标识；默认统计仍包含被删除 Key 的历史记录。
- 删除后的 Key 不再出现在筛选下拉框中，但历史明细仍可见；不增加回收站或批量删除。
- 前端增加“删除”与确认弹窗，文案说明只移除密钥列表记录，历史调用与费用保留。

## 验收

1. 已撤销 Key 有删除操作，可用 Key 无删除操作。
2. 取消确认无请求；成功后列表和数量更新；刷新后仍不可见。
3. 后端拒绝删除可用 Key（409）；他人和不存在 Key 返回相同 404。
4. 删除需要会话与 CSRF；未登录、缺失 CSRF 与现有管理接口语义一致。
5. 同一用户重复删除已删除 Key 幂等成功，不改变第一次 deleted_at。
6. 删除前后历史调用数、费用总额与历史脱敏标识保持一致，Key 继续无法推理。
7. 错误在确认弹窗中显示，键盘操作与现有弹窗一致。

## 边界

不物理删除 Key、调用或费用，不修改已有字段含义、价格、计费或模型约束；保留用户已有修改，不自动提交。
