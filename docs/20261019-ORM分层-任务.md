## 隔离运行与安全边界

隔离测试需要 PATH 中已有 mysqld 和显式 LAYA_TEST_ORM_MYSQL=1。测试自行创建
/private/tmp/modeltoll-orm-* 临时目录，启动仅 loopback 随机端口、随机临时密码的 MySQL，
不加载真实 .env；external/offline 模式禁止加载模型，结束后停止自己启动的实例并清理
该实例目录。不会创建/删除现有服务的库、表、用户或数据，不使用 ORM 建表。
默认 unittest 不启动 MySQL；没有 mysqld 时不能宣称真实锁验收通过。
