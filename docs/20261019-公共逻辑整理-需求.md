# 公共逻辑整理需求

用户在成功响应封装后明确要求“都优化吧”，确认前一轮列出的四项建议。

范围：公共错误内容和 HTTP 异常构造；公共有限请求体读取；管理员服务去除成功 code；
统计响应共用 UTC range 构造及已有时间格式化。
现有成功响应封装未提交，必须保留。其他历史待办不纳入本轮。

验收：HTTP 完整响应格式、状态码、Cookie、X-Request-Id/Retry-After 不变；
网关 256 KB/解析前读取、品牌 3 MB/管理员与 CSRF 后读取的顺序不变；
管理服务仅返回业务字段，API 仍添加 code；统计范围、时区、秒精度和查询限制不变。
默认回归通过，完整 OpenAPI 相同。无 SQL、事务、模型、依赖或前端改动。
不自动提交、推送、部署或重启，不操作真实账号与账务数据。
