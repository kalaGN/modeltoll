## 页面结构

- 三个管理页面使用具名 CSS 类共享侧栏、页眉、指标、表格与筛选样式。
- 暖白主画布、墨绿侧栏、酸橙主操作；不加入效果图中无现有功能支撑的工作空间切换、脱敏密钥复制或文档按钮。

- 登录品牌区采用原创几何图形与功能介绍，替换旧的静态演示数据；保留现有内联登录逻辑和所有表单钩子。
- 统计页保持当前 UTC 文案、价格规则、金额精度、分页和筛选；图表换为墨绿色。
- 小屏侧栏转顶部导航；筛选器纵向排列，表格与代码独立滚动。

## 交互与兼容

弹窗增加 dialog 语义、焦点约束与焦点恢复。密钥展示弹窗仅通过“我已保存”关闭，避免误触丢失一次性密钥；复制反馈在每次打开时复位。
错误消息在弹窗内可见；保持请求内容与状态码。减少动画设置关闭非必要动画。
服务端创建响应中的调用示例含完整密钥，页面展示时替换为 `YOUR_API_KEY`，避免关闭弹窗后完整值继续出现在示例面板。
样式仅依赖当前 DOM 与具名类，不引入前端路由或模板框架。
