# Vue 前端重做需求

状态：用户通过“完成重做并提交推送代码”确认方案与实施、提交和推送范围，已实施。

## 目标与假设

将现有原生 ES Modules 多页前端改为 Vue 单文件组件应用；默认保留现有暖白/墨绿视觉、
页面功能与后端 API，不额外做视觉重设计。先交付登录页样板确认，再迁移其余页面。

保留 /login、/register、/keys、/usage、/billing、/admin、/admin/settings、/admin/users，
以及根路径按角色导航。覆盖登录/注册/退出、品牌、Key 创建/撤销/隐藏、调用/费用筛选与
分页、管理员总览、品牌/Logo/模型连接配置及测试、用户停用/启用、Key 撤销及审计列表。

鉴权仍为 Cookie + Double-Submit CSRF；前端守卫不代替后端权限。完整 Key 仅在创建后
按既有交互展示，不写 localStorage；品牌和错误内容不以不可信 HTML 渲染。

## 边界与验收

- 不改后端、数据库、接口字段/状态码、计费与限流政策；保留当前后端未提交修复。
- 本地仍前端 5173、后端 8000，同源代理；生产仍独立 Nginx 前端。
- 直接打开/刷新所有深层 URL 正常；接口错误不被 SPA fallback 替换成 HTML。
- 未登录、普通用户访问管理页、会话失效、CSRF 首次初始化均有回归。
- 保留加载/空数据/失败/提交中状态、移动端表格滚动与模态框键盘操作。
- 旧功能断言保留，测试可由旧模块结构断言调整为 Vue 组件/路由/行为断言，不直接删测试。
- 用户已显式授权本轮 Vue 改动提交推送；不自动重启或修改真实账号，浏览器验证使用合成 fixture。

已确认采用设计中的技术栈、SPA 入口位置、旧前端替换范围和测试依赖；验证见任务记录。
