# Service 业务分组需求

状态：2026-10-19 用户确认四个业务域目录及 utc_now 迁移，授权实施。

当前 services 平铺 15 个实现模块，账号、推理、计量和平台服务混合。
目标：按 access、inference、metering、platform 分组，仅增加一层包；
utc_now 从 accounts 移至已有 core/time.py，消除通用时间能力对账号服务的依赖。

范围包括全部调用方、CLI、测试内 patch 字符串及嵌入的容器测试脚本。
不改 API、业务规则、事务、SQL、数据库、依赖和部署；不顺带迁移 api/errors.py。
验收：默认回归全通过、完整 OpenAPI 不变、新目录边界有测试、旧模块引用无残留。
不自动提交、推送、重启服务或访问真实业务数据。
